# 🌸 Iris Flower Prediction using Machine Learning

## 📌 Project Overview
This project uses Machine Learning to predict the species of an Iris flower based on its measurements.

A Decision Tree Classifier is used to classify flowers into three categories:
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 🎯 Project Objective
To build a simple Machine Learning model that can predict the type of Iris flower using four input features.

## 📊 Dataset
The built-in Iris dataset from Scikit-learn is used.

**Features:**
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

**Target Classes:**
- Setosa
- Versicolor
- Virginica

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib

## 🤖 Machine Learning Algorithm
**Decision Tree Classifier**

The dataset is divided into:
- 80% Training Data
- 20% Testing Data

The model is trained using training data and evaluated using testing data.

## 📈 Model Evaluation
Model performance is evaluated using Accuracy Score.

An accuracy graph is also created using Matplotlib.

## 🔍 Sample Prediction
The model predicts the flower species using these sample measurements:

`[5.1, 3.5, 1.4, 0.2]`

**Predicted Flower:** Iris Setosa
